# Desafio Fotos - Sistema de Flashcards Enriquecidos

Sistema para gerar cards enriquecidos de perguntas de Exames;

Sistema multi agentes que :
1 - coordenador 
2 - cria os cards de perguntas e opções - criador
3 - traduz os cards de perguntas e opções - tradutor
3 - Enriquece os cards de perguntas - resolvedor tecnico
    Ele coloca uma explicacao tecnica, explica o ponto central da Questão, e quais alternativas são erradas ou a quase certa da Resposta Correta 100%
    Use o template templates/001-enriched-card.md
4 - Enriquece as perguntas for kids - professor didatico e lúdico
    Ele faz a mesma coisa que o Resolvedor tecnico mas mas focada para ser ludico e simples como se explicasse para uma criança de 10 anos o problema.
    Use o template templates/001-enriched-card-for-kids.md
